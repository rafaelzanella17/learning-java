# Exercícios — Matrizes (Java)

## 1. Soma de todos os elementos da matriz  
Crie uma matriz `int[][] numeros = {{2, 4, 6}, {1, 3, 5}};`  
Escreva um programa em Java que **some todos os valores da matriz** e imprima o resultado final na tela.

---

## 2. Encontrar o maior valor em uma matriz  
Dada a matriz `double[][] valores = {{7.5, 2.3, 9.8}, {6.1, 8.0, 4.4}};`  
Crie um código Java que **percorrra a matriz e encontre o maior valor**, mostrando também **a posição (linha e coluna)** onde ele está.
