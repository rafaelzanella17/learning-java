# Exercícios — Arrays em Java

Abaixo estão três exercícios baseados no exemplo mostrado no arquivo Arrays.java.  
Cada exercício deve ser feito criando um novo arquivo `.java` separado.

---

## 1. Exercício — Somar Todos os Valores do Array
Crie um programa que:

- Crie um array de inteiros igual ao do exemplo `{10, 20, 30, 40, 50}`.
- Some todos os valores do array utilizando um **for padrão**.
- No final, exiba no console:  
  **"A soma dos valores do array é: X"**

---

## 2. Exercício — Encontrar o Menor e o Maior Valor
Crie um programa que:

- Crie um array com valores fixos.
- Percorra o array usando **for-each**.
- Encontre e exiba o **menor** e o **maior** número da lista.  
  Exemplo de saída esperada:  
  **"Menor valor: 10 | Maior valor: 50"**

---
