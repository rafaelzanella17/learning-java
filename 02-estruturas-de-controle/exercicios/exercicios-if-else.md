# Exercícios de Condicionais em Java — IF / ELSE IF / ELSE


### 1. Verificar se um número é positivo
Crie um programa que leia um número inteiro e imprima **“Positivo”** caso ele seja maior que zero.

### 2. Conferir se a idade permite votar
Leia a idade do usuário e exiba **“Pode votar”** se a idade for maior ou igual a 16 anos.

### 3. Verificar se um produto está em promoção
Crie uma variável `boolean emPromocao = true;`  
Se for **true**, imprima “Produto em promoção!”.

### 4. Número par ou ímpar
Leia um número inteiro e informe se ele é **par** ou **ímpar**.

### 5. Validação de usuário
Leia uma `String senha = "1234";`  
Se for igual a `"1234"` exiba “Acesso permitido”, senão “Acesso negado”.

### 6. Verificação de maioridade
Leia a idade do usuário.  
Se for maior ou igual a 18, imprima “Maior de idade”, senão “Menor de idade”.

### 7. Classificação de nota
Leia uma nota de 0 a 10:
- Se for > 7: “Aprovado”
- Se for entre 4 e 6: “Recuperação”
- Se for < 4: “Reprovado”

### 8. Temperatura do clima
- Se temperatura < 15: “Frio”
- Se temperatura entre 15 e 25: “Agradável”
- Se temperatura > 25: “Quente”

### 9. Classificação de velocidade
Leia a velocidade atual:
- < 40: “Muito lento”
- 40 a 80: “Velocidade normal”
- > 80: “Acima do limite!”
