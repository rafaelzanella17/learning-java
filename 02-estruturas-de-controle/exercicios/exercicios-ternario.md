## Operador Ternário — Exercícios

### 1. Verificar maioridade
Use ternário para imprimir:
`idade >= 18 ? "Adulto" : "Não adulto"`.

### 2. Checar se número é par
Use ternário para imprimir:
`num % 2 == 0 ? "Par" : "Ímpar"`.

### 3. Comparar preços
Crie duas variáveis `preco1` e `preco2`.  
Use ternário para mostrar qual é o menor preço.
