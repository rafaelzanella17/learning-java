# While — Exercícios

```
1. Contagem crescente  
Crie uma variável `i` iniciando em 1.  
Use `while` para imprimir os números de 1 até 50.
```

```
2. Somar valores  
Peça para o usuário digitar números repetidamente.  
Use `while` para continuar lendo até que ele digite `0`.  
Mostre ao final a soma de todos os números digitados.
```

```
3. Contar números pares  
Use `while` para percorrer os números de 1 a 100.  
Conte quantos números pares existem e imprima o total ao final.
```

# Do While — Exercícios

```
1. Validação de senha  
Peça para o usuário digitar uma senha.  
Use `do while` para repetir a pergunta até que ele digite a senha `"1234"`.
```

```
2. Menu interativo  
Crie um menu com as opções:  
1 - Exibir mensagem  
2 - Mostrar número aleatório  
0 - Sair  
Use `do while` para repetir o menu até que o usuário escolha `0`.
```

```
3. Repetir leitura até valor positivo  
Use `do while` para pedir ao usuário um número.  
Continue pedindo até que ele digite um número maior que 0.  
Depois imprima o número digitado.
```
