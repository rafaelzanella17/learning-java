# Exercício 1 — Switch Case (Dia da Semana)

Crie um programa em Java que receba um número de 1 a 7  
e exiba o dia da semana correspondente.

**Exemplo:**  
1 → Segunda-feira  
2 → Terça-feira  
...  
7 → Domingo

# Exercício 2 — Switch Case (Menu de Operações)

Crie um programa que apresente um menu:

1 - Cadastrar  
2 - Alterar  
3 - Excluir  
4 - Listar  

Use `switch` para exibir a mensagem correspondente à opção escolhida.  
Se o usuário digitar algo diferente, exiba "Opção inválida".

# Exercício 3 — Switch Case (Classificação por Nota)

Peça ao usuário uma nota de 0 a 10 e use `switch` para classificar:

- 10, 9 → "Excelente"
- 8, 7 → "Muito bom"
- 6, 5 → "Regular"
- 4, 3 → "Ruim"
- 2, 1, 0 → "Muito ruim"

Caso o valor seja fora do intervalo, retorne "Nota inválida".
