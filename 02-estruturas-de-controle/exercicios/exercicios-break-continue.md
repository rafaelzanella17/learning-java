# Break no For — Exercícios

```
1. Parar ao encontrar número específico  
Use um `for` para percorrer os números de 1 a 20.  
Faça o loop parar (break) quando o número for igual a 13.
```

```
2. Buscar o primeiro número par  
Use um `for` percorrendo de 1 a 50.  
Quando encontrar o primeiro número par, exiba-o e use `break` para parar.
```

```
3. Interromper busca por senha  
Simule um loop com tentativas (3 tentativas).  
Pare o `for` usando `break` quando o usuário digitar a senha correta.
```

# Continue no For — Exercícios

```
1. Pular múltiplos de 3  
Use um `for` de 1 a 30.  
Use `continue` para pular os números que são múltiplos de 3.  
Imprima apenas os restantes.
```

```
2. Mostrar apenas números pares  
Use um `for` de 1 a 20.  
Use `continue` para ignorar números ímpares.  
Mostre somente os números pares.
```

```
3. Ignorar posições proibidas  
Percorra um `for` de 1 a 10.  
Use `continue` para pular as posições 4 e 7.  
Imprima todas as outras.
```
