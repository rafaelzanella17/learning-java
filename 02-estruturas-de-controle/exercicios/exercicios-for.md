# For — Exercícios

```
1. Contagem de 1 a 20  
Use um `for` para imprimir os números de 1 até 20.
```

```
2. Tabuada  
Peça ao usuário um número.  
Use um `for` para exibir a tabuada desse número de 1 a 10.
```

```
3. Contar números ímpares  
Use um `for` para percorrer os números de 1 a 50.  
Conte quantos números ímpares existem e imprima o total ao final.
```
